4. Advanced Tutorial
====================

Use this chapter for optional projects such as LVGL interfaces, motion-based
interaction, TF card data logging, image resource loading, Wi-Fi dashboards,
Bluetooth control, or custom firmware.

Project List
------------

.. list-table::
   :header-rows: 1
   :widths: 30 50 20

   * - Project
     - Description
     - Required Tools
   * - LVGL display interface
     - Build a richer embedded UI on the 1.83-inch TFT LCD.
     - Arduino IDE or ESP-IDF, LVGL, LCD driver
   * - Motion data logger
     - Read QMI8658A motion data and save records to the TF card.
     - Sensor library, TF card library
   * - Wireless status panel
     - Show Wi-Fi or Bluetooth device status on the onboard screen.
     - Wi-Fi or Bluetooth examples

Project Template
----------------

Overview
--------

Describe what the project does and what users will build.

Prerequisites
-------------

* Arduino IDE or ESP-IDF, depending on the project.
* ESP32-S3 1.83-inch LCD Development Board.
* Included TF card if the project reads or writes files.
* Any project-specific libraries listed by the example.

.. warning::
   If this project uses a paid API or third-party cloud service, state that
   cost and account requirements may be separate from the product purchase.

Steps
-----

1. Prepare the project files.
2. Configure credentials or model files if required.
3. Build or run the project.
4. Verify the result.

Troubleshooting
---------------

Use symptom, cause, and fix entries for common failures.
