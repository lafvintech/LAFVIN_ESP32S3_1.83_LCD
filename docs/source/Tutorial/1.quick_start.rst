1. 快速入门
===========

本章用于帮助你在收到开发板后，快速确认 ESP32-S3 1.83-inch LCD 是否可以正常工作。

开发板出厂前通常已经预置出厂测试固件。上电后，屏幕会显示开发板的基础测试信息，
例如 SD 卡容量、Flash 大小、传感器数据、无线扫描结果、背光等级等内容。通过这些
信息，你可以先确认屏幕、存储、传感器、无线功能和背光控制是否正常。

.. note::
   本章只是快速入门，用于完成开箱验证和固件体验。如果你想学习完整开发流程，请继续阅读
   :ref:`Arduino 教程 <arduino_tutorial>`。

准备工作
--------

* 使用 USB Type-C 数据线连接开发板。仅供电线可以点亮开发板，但不能用于烧录或串口通信。
* 如果需要查看串口日志，请确认电脑已经识别到开发板串口。
* 如果要使用在线烧录工具，请使用支持 Web Serial API 的 Chrome 或 Edge 浏览器。
* 如果要测试 SD 卡相关信息，请插入套件中附带的 1 GB TF 卡。

步骤 1：连接开发板
------------------

1. 使用 USB Type-C 数据线将开发板连接到电脑。
2. 等待开发板上电启动。
3. 观察 1.83 英寸 LCD 屏幕是否点亮。
4. 如果开发板没有立即启动，可以按一次 **RST** 按键重新启动。

预期结果
~~~~~~~~

屏幕应显示出厂测试固件界面。不同批次的固件界面可能略有差异，但通常会包含以下
一项或多项信息：

* SD 卡容量或 SD 卡检测状态
* Flash 容量
* QMI8658A 传感器数据
* Wi-Fi 无线扫描结果
* 背光等级或背光调节状态

如果这些信息可以正常显示，说明开发板的主要板载功能已经可以工作。

步骤 2：恢复出厂测试固件
------------------------

如果开发板没有显示出厂测试界面，或者你已经烧录过其他程序并想恢复出厂状态，可以使用
:ref:`online_flasher` 重新烧录出厂测试固件。

在线烧录适合以下场景：

* 恢复出厂测试固件
* 验证开发板功能是否正常
* 快速体验官方提供的其他固件
* 在不安装 Arduino IDE 或 ESP-IDF 的情况下烧录固件

.. warning::
   烧录新固件会覆盖开发板中当前运行的程序。如果你需要保留当前程序，请先确认你拥有对应的
   源代码或固件文件。

步骤 3：进入正式课程
--------------------

完成快速验证后，你可以根据自己的开发方式选择后续课程：

* 如果你是初学者，或希望快速上传示例程序，请阅读 :ref:`Arduino 教程 <arduino_tutorial>`。
* 如果你只想体验不同功能固件，可以继续使用 :ref:`online_flasher` 选择并烧录其他固件。

常见问题
--------

**屏幕没有显示内容**

* **现象**：连接 USB 后，LCD 没有点亮或没有显示测试界面。
* **可能原因**：USB 线供电不稳定、开发板未正常启动、出厂固件被覆盖。
* **解决方法**：更换 USB 数据线，按一次 **RST**，或使用 :ref:`online_flasher`
  恢复出厂测试固件。

**电脑没有识别到串口**

* **现象**：设备管理器或开发工具中没有出现可用串口。
* **可能原因**：使用了仅供电 USB 线、USB 驱动未安装、USB 口接触不良。
* **解决方法**：更换 USB Type-C 数据线，尝试其他 USB 接口，并参考 :ref:`preparation`
  检查开发环境与驱动安装步骤。

**在线烧录无法连接开发板**

* **现象**：浏览器中无法选择串口，或点击连接后失败。
* **可能原因**：浏览器不支持 Web Serial API、串口被其他软件占用、开发板未进入可烧录状态。
* **解决方法**：使用 Chrome 或 Edge 浏览器，关闭串口监视器等占用串口的软件；如果仍然失败，
  按住 **BOOT**，短按 **RST**，松开 **BOOT** 后重新连接并烧录。
