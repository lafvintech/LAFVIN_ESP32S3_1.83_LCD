About This Kit
==============

Product Overview
================

The ESP32-S3 1.83-inch LCD Development Board is a compact color-display
development board for IoT, smart hardware, embedded UI, and maker projects.
It combines an ESP32-S3 N16R8 controller, 16 MB Flash, 8 MB PSRAM, Wi-Fi,
Bluetooth, a TFT LCD, a six-axis motion sensor, and a TF card slot on one
breadboard-friendly board.

The board is designed for students, makers, and embedded developers who want
to learn ESP32 development, prototype connected devices, build small graphical
interfaces, or create motion-aware projects.

.. note::
   Use a USB Type-C data cable when programming the board. Charging-only
   cables can power the board but cannot be used for firmware upload or serial
   communication.

Key Features
============

* **Controller**: ESP32-S3 N16R8 dual-core MCU
* **Memory**: 16 MB Flash and 8 MB PSRAM
* **Wireless**: Wi-Fi and Bluetooth
* **Display**: 1.83-inch TFT LCD, 240 x 284 resolution, 4-line SPI, 262K colors, ST7789 driver
* **Motion Sensor**: onboard QMI8658A six-axis accelerometer and gyroscope
* **Storage**: onboard TF card slot for external storage, image resources, and data logging
* **Expansion**: unused GPIO pins are routed to headers for breadboard-compatible prototyping
* **Development**: supports Arduino IDE and ESP-IDF
